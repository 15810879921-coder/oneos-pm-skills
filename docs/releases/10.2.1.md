# 云效生命周期 10.2.1：安装版本强制回读

发布日期：2026-09-16。维护范围：五个 Codex Skill；Cursor 历史包未修改。

[团队更新入口](https://15810879921-coder.github.io/oneos-pm-skills/#lifecycle-10-2-1)

## 本次变化

- 开发大脑在读取、判断、引用或执行五个云效生命周期 Skill 前，先运行每日更新器，再从用户级安装目录重新定位并读取当前 `SKILL.md`。
- 会话缓存、源码工作树、发布说明、更新前读取结果和更新命令退出码均不能单独证明本机当前版本。
- `skipped-today` 仅证明当天曾成功运行更新器。同日出现远端新提交、新发布版本、源码与安装目录不一致或用户报告版本落后时，使用 `--force` 绕过成功缓存并重新同步。
- 更新进行中时，不报告当前版本，也不开始生命周期写入；更新失败不阻断普通本地开发，但不能宣称安装为最新版本。
- 五个 Skill 统一升级为 10.2.1；10.2.0 的交棒、测试、完成开发和发布门禁保持兼容。

## 验证要求

- 每日更新器覆盖普通首次更新、当日跳过、失败冷却、并发锁和 `--force` 强制刷新。
- 五个安装包必须保持相同版本和相同更新器字节，并通过包清单、逐文件内容与 SHA 校验。
- 安装页复制内容必须要求五个 Skill 均为 10.2.1，且继续只维护 Codex 包。
- 发布后在真实用户级安装目录强制更新，逐个回读五个版本、修改时间和开发大脑约束文本。

本次没有修改业务仓、云效工作项、流水线或生产环境。
