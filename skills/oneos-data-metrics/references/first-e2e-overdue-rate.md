## 1. 业务前置（合规官 · 引用，不重裁）

- **裁决要点**：逾期 = 当前日期 **>** 账单到期日 + 该客户宽限天数；宽限期内不判逾期。  
- **宽限取值**：KA 15 / LA 10 / SMB 6（业管在客户管理维护）。  
- **锚点**：`biz-finance-integration` → metric `grace-days`；术语 `grace-period`。  
- **分级变更生效时点**：合规官侧仍标缺口 → 本卡排除项写清「分级变更适用时点未定稿则按账单生成时分级」。

## 2. 指标口径卡

```markdown
## 指标口径卡
- 指标名 / 别名：逾期账单率 / 逾期率（别名收敛到本卡，禁另起算法）
- 一句话业务含义：统计期末，仍处于逾期状态的租赁账单笔数，占同期应观察账单笔数的比例。
- 分子：统计期末状态为「逾期」的租赁账单笔数（已适用宽限期判定）
- 分母：统计期内曾达应付日、且纳入观察的租赁账单笔数（见对象范围）
- 时间窗：按「账单到期日」落在观察窗 [start, end]；状态取观察窗末日快照
- 对象范围：已生效租赁合同下的租赁账单；币种/主体以业管指定账套为准（未指定则标缺）
- 排除项：
  - 宽限期内账单（未过「到期日+宽限」）
  - 已作废 / 已冲销账单
  - 减免停租已全额核销且无剩余应付的账单
  - 非租赁类应收（提车应收、还车应收等）——不进本分母
- 数据来源：status=unmapped；待探针报告回填表字段。本期禁止用 mock 数对外。
- 业务前置裁决：宽限期内不算逾期（见 §1）；分级变更时点缺口不脑补。
- 口径版本 / 生效日：v0.1 / since=null（未上现网；note：纸面 E2E 首卡）
- 置信度：中（业务判定有定版；取数未对表）
```
