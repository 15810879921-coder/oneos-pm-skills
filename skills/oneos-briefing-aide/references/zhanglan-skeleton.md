# 张兰总口径 · 一线培训骨架

> 金样是《任务工单怎么用》的**叙事节拍**，不是进度周报，也**不是视觉母版**。  
> 换模块时 **换内容、不换节拍**；落地页用仓库已有汇报舱/业务页皮，禁止照抄金样 HTML。  
> **精髓**：把对象教成「一张单怎么用」——两种进来、一个中心、三种看法仍是同一张、**单上角色**（发起/主责/协办/归口/抄送）先于岗位编制、收到后三拍、截图只找位置、两条演示后自己做一遍、FAQ 打固定误会、收口四句。禁止写成模块对照表、岗位说明书或「工单 vs 另一本账」开篇。  
> **产品方案 / 内部图解不要用本文件。** 改走 [`zhanglan-scheme.md`](zhanglan-scheme.md)。董事长大屏走 `pdf-report-plain-language`。

## 0. 写之前问自己

1. 听众听完要能做什么？（找到工单 / 接单 / 提交结果……）  
2. 他们最容易误会哪一件？（常：把视角当成多套系统、把入口当成两套流程）  
3. 收口要留下哪 3～5 句？

这三问答不出 → 不要动笔。

## 1. 一页节拍（强制顺序）

```text
顶栏（产品名 · 材料性质）
 → Hero：人话标题 + 一句话定义 + 一句总答案（锚）
 → 目录（听众的问题，不是系统菜单）
 → 入口（≤2 为主；各带例子 + 这条主要干什么）
 → 收敛图（多入口 → 同一个中心）+ 六步短流程
 → 视角消毒（看起来像多套 = 只是查看范围）
 → 角色表（先找到自己是谁）
 → 动作三拍（收到时 / 处理中 / 完成后）+ 一条「不属于你时怎么办」
 → 截图（有则标注 1/2/3；无则占位，禁止空图墙）
 → 现场演示两条完整场景 + 培训后自做一遍
 → FAQ（打误会）
 → 收口 N 句
```

可裁：截图未定版 → 留占位，不删整节。  
不可裁：Hero 总答案、收敛、角色、三拍、收口句。

## 2. 金样节拍（任务工单 · 只记结构）

| 节 | 她怎么写 | 可复用句式 |
|----|----------|------------|
| 标题 | 「任务工单怎么用」 | `{事物}怎么用` |
| 定义 | 需要有人负责、限时处理、最后有结果的事情，都可以进入… | 什么条件下进入这件事 |
| 总答案 | 不管 AI 还是人工发起，最后都在同一个工单中心处理 | 不管 A 还是 B，最后都在同一个 {中心} |
| 入口 | 群机器人 / 员工人工；各 4 个例子 + 一句「这条主要处理什么」 | 来源 + 例子 + 边界 |
| 收敛 | 两种方式 → 统一工单中心；不需要多个地方重复登记 | 杀「分别处理几张相同的单」 |
| 流程 | 发起→指定负责人→接单→提交结果→验收→结束 | 人话六步，不写状态枚举 |
| 视角 | 全局 / 部门 / 我的 = 查看范围；同一张单可同时出现 | 「不是三种 {事物}，也不是三套系统」 |
| 角色 | 发起人 / 主负责人 / 协办人 / 归口 / 抄送 | 职责一句话；协办 ≠ 最终责任 |
| 三拍 | 看清事项与时限 → 进展与超时说明 → 结果+证明+验收才结束 | 每步留下必要说明 |
| 注意 | 不属于自己时不要放着不管：转交、退回或联系发起人 | 一条防「不是我的就晾着」 |
| 演示 | AI 故障一条、人工创建一条 | 截图找位置，演示走全流程 |
| 收口 | 四句：自动发起、人工也可、视角不是三套、人+时限+结果+确认 | 能背走 |

## 3. 节模板

### Hero

```text
材料性质：培训材料 / 一线说明 / 操作入门
标题：{事物}怎么用
定义：{什么情况下用它}。
总答案：{不管从哪来，最后怎么处理}。
```

### 入口卡

```text
N. {来源名}
一句话：谁、在哪、触发什么。
例子：3～5 条真实场景（不要功能名）。
边界：这条主要处理什么；什么情况走另一条。写进该入口自己的格子，**禁止把「不做」单起一行冒充「谁负责」**。
```

### 角色行

```text
{角色}：{要完成的动作}。不要写权限矩阵。
```

### 三拍

- 收到时：看清事项、确认自己是不是主责、看时限、不清就问  
- 处理中：有进展就写、要配合就加人、走不下去写原因、可能超时提前说  
- 完成后：写结果、交证明、交给确认人、确认通过才结束  

### 收口句

3～5 句，每句一个可带走的事实。禁止「更多功能请见系统」。

## 4. 反例（金样对照）

| 错法 | 为什么翻车 | 改成 |
|------|------------|------|
| 「本模块包含全局工单、部门工单、我的工单三大子系统」 | 一线以为要办三次 | 同一张单，三种查看范围 |
| 「工单状态机：Draft→Assigned→…」 | 黑话，记不住 | 发起→负责人→处理→结果→确认→结束 |
| 开篇「为提升协同效率，平台打通…」 | 空话，无锚 | 一句话定义 + 一句总答案 |
| 先贴 12 张菜单截图 | 找不到自己要干什么 | 角色 → 三拍 → 再标截图 1/2/3 |
| 结尾「如有问题请联系管理员」 | 带不走 | 收口四句 |
| 给董事长页写「请各部门按周拆解、过程留痕」 | 内部管理进决策层 | 那页走 `pdf-report-plain-language`，不走本骨架 |

## 5. 换模块速填

把「工单」换成目标事物，检查这五句是否仍成立：

1. 什么情况下进入它？  
2. 从哪进来，最后是否同一个中心？  
3. 看起来像多套的，是不是只是视角？  
4. 谁负责、谁配合、谁确认？  
5. 收到 / 处理中 / 完成后各做什么？
