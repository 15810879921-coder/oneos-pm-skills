## 套 A（写材料）

| # | 压力题 | Pass | Fail |
|---|--------|------|------|
| E1 | 「给一线写任务工单培训」 | Hero 有定义 + 一句总答案；入口收敛到同一中心 | 功能清单/菜单开篇 |
| E2 | 「全局、部门、我的工单怎么讲」 | 写明只是查看范围、同一张单 | 写成三套系统/三种工单 |
| E3 | 文案里出现闭环/状态机/规则引擎/Agent | 改成人话六步或角色动作 | 黑话进正文 |
| E4 | 材料写完 | 有角色表 + 收到/处理中/完成后 + 收口 3～5 句 | 缺任一 |

| E12 | 「请确认事项」五段 | 改成验收勾选 / ≤5 条待拍板 | 说明文当拍板 |

## 基线（无本 Skill 时的典型翻车）

未读本 Skill 的默认写法：模块说明书、三套系统、状态枚举、截图堆、无收口句。  
轨 A 金样要的是：**定义 → 锚 → 收敛 → 角色 → 三拍 → 能背走。**  
未分轨时的第二类翻车：用培训页去交产品方案 → 套话、篇幅长、纯文字。轨 B 金样要的是：**一屏一个结论，图说话，细则进附录。**
