## 本次变化

| 岗位 / Skill | 必须满足的交棒条件 |
| --- | --- |
| 产品 / YunxiaoPM | 冻结合同、验收、不做项和工程决策清单；需求与全部当前端侧交付回读同版 manifest；初始化只到设计完成，formal:false；单独正式交棒校验后才待开发 |
| 开发 / yunxiao-development-delivery | 开工与完成均实时核对资料、任务真实归属、同版理解回执和工程决策；保留原提交后完成判断及可恢复执行器 |
| 知识层 / development-brain | 历史知识与岗位方法不能覆盖当前冻结合同；不要求同事复制产品经理本机分身或私人记忆 |
| 测试 / YunxiaoQA | 对齐当前 scope、开发/测试任务、部署版本和真实执行 ID；逐验收项实际通过；行政完成仍 formal:false，不能用于发布 |
| 发布 / yunxiao-release-operations | 当前正式交棒包、逐项 QA PASS、精确版本和未决工程事项同时校验；发布动作绑定同一冻结来源的仓库/MR/流水线/应用；停止、取消等减险操作保留原安全入口 |

交棒版本变化会使受影响 scope 的旧回执失效；只需重读变更及必要依赖，不扩大为无关资料全量阅读。工程判断由负责人确认，AI 不得自行把未知补成“同意”。

## 使用与边界

同事在各自 Codex 更新五个 Skill，并核对版本均为 10.2.0，随后新开会话。当日自动更新已执行并不代表刚发布的版本已装上。10.1.x 的 standard 预检需重做：初始化不再一步报正式待开发；冻结完成后使用 `preflight-handoff / apply-handoff`。开发历史提交/账本兼容规则保留。

本次没有写真实云效工作项、执行流水线或发布生产。离线测试、仓库发布及安装包校验不等于真实平台演练，也不等于全员已经更新或服务端强制门禁已开启。若要求平台上不可绕过，需另行授权在 CI/组织工作流接入校验。

资料 URL 只适用于产品负责人确认的受控团队来源；现有读取器没有不可信 URL 的主机/内网/重定向隔离，不应当作通用安全抓取器。受控认证资料需合规适配，不能为了过门禁公开敏感文档。PM 全端检查采用项目交付分页查询与正向关系核验；大项目的限流/性能尚未实测。哈希与回执能检查一致性，不能替代人类真实理解和复核。

本轮没有可新增到个人知识库的通用候选；规则随 Skill 仓库维护，不写产品经理个人记忆。
