# 库与现网漂移预警

> **进化任务**：`evo-kb-drift-watch`  
> **版本**：v1.0.0 · 2026-08-21  
> **硬闸**：发现漂移 → **主动报缺口**（作战室 `defects[]` 或交棒给产品）；禁假装库仍准。合规官**只读**，不自行改库。

## 0. 什么叫漂移

| 类型 | 信号 | 谁发现 |
|------|------|--------|
| **现网改了库没改** | 生产菜单/字段/门禁与 `machine/rules` 或 `modules/*.md` 冲突 | 研发 / 测试 / 对照生产改页时 |
| **库改了现网没跟** | 定版口径已入库，现网仍旧行为 | 产品验收 / 合规官裁决 |
| **术语双写** | 卡内又写了一遍 glossary 已有定义 | 典藏官入库自检 |
| **断供** | 某条线 ≥1 个双周无新料且现网有大改 | 典藏官例行 |

## 1. 报缺口模板（可贴作战室 / 聊天）

```markdown
## 知识库漂移报告
- 发现人 / 日期：
- 类型：现网超前 | 库超前 | 术语双写 | 断供
- 现网证据：（URL / 截图 / 菜单路径 / 探针报告路径）
- 库内锚点：（machine/rules/<id>.json 或 modules/<id>.md · 条款原文）
- 冲突一句：
- 建议：改库 | 改现网 | 待合规官裁 | 待本尊拍板
- 缺口 ID：（写入后回填）
```

## 2. 分诊后动作

```text
原料/冲突进来
 → 定版可入？ → 是：典藏官改库 + 跑 retrieval-eval 相关题
 → 业务存疑？ → 合规官裁完再入
 → 现网该改？ → 交产品/开发，库保持定版并标 note
 → 未定版？ → 拒收；禁入库「讨论稿」
```

## 3. 例行（轻量）

| 时机 | 动作 |
|------|------|
| 入库收口 | 扫本卡 `sources` / `sourceRefs` 是否仍指向有效路径 |
| 对照生产改页 | 强制过本 Skill「漂移」一眼；有冲突就开报告 |
| 双周复评 | 扫「断供」：manifest 条线是否零增量 |

**不做（本波）**：自动 Diff 生产 schema、爬虫扫站、假绿灯巡检脚本。预警 = **人+规程**；自动化属远程。
