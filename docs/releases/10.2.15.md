# 云效生命周期 Skill 10.2.15

本版补齐测试发现缺陷后的开发特殊修复通道，保证测试证据、开发动作和Bug最终状态形成可回读闭环。

## 变化

- QA 新增 `yunxiao_cli_bug_repair_request.py` 和 `提交缺陷修复请求`。
  - 校验Bug与【测试】正式关系、当前状态、复现步骤、实际/期望结果和证据引用。
  - 以 `oneos.test-bug-repair-request/v1` 追加评论，保存证据哈希和当前测试用户。
  - QA 不改Bug状态、不改代码，评论写入后必须官方回读。
- 开发新增 `yunxiao_cli_bug_repair_channel.py` 和 `处理测试修复请求：缺陷=<ID>`。
  - 重新核验最新请求、Bug负责人和可处理状态。
  - 追加 `【开发接收测试修复】` 评论后直接复用既有 `修复bug:<ID>` 链路。
- Bug 收口新增 `暂不修复` 受控路径：必须提交原因、批准人、批准证据和后续动作，追加 `oneos.bug-deferred-fix/v1` 后才允许写状态。
- `已修复` 仍必须有真实开发验证、MR 合并和合并版本回读；两种状态都不等于测试通过或Bug关闭。
- 五个云效生命周期 Skill、索引和 Codex 包统一版本为 `10.2.15`。
