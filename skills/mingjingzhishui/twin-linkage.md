## 0b. 本尊口令速查（v1.0.11 · 用途名）

| 你想… | 喊谁 / 说啥 | 下一棒 |
|--------|-------------|--------|
| 定需求 / 改 PRD / 出交棒 | **产品交付**（言出法随）·「出交棒包」 | 贴包 → **开发落地** |
| 规则 / 能不能做 / KB | **业务口径**（法眼如炬） | 产品收口③ → 必要时改包 |
| 按包落地 | **开发落地**（明镜止水）·「按交棒落地」 | 回执 → **测试验收** |
| A 已绿，进真仓 | 本尊点头 +「**进 B**」 | 开发落地只动 `~/oneos-prod` |
| 工程卡死 | **不用喊名**；产品代挂或开发旁路 | 「## 明镜建议」解阻 |
| 回执待拍板 | 本尊拍板 → 产品「**改包再交**」 | 开发停手等新包 |
| 交棒 vs 现网/KB | 「**升业务口径**」 | 裁完改包再交 |
| 测试 / 证据 / 打回 | **测试验收** | 不进上线守闸 |
| UI / AI 交互规范 | **体验规范** | 回写产品原型纪律 |
| 发版上线 | **本尊自留**（上线守闸休眠） | — |
| 不知道喊谁 | **任务指路** | — |
| 只改文案/样式 / 点名主题 CSS | 产品窄例外 | **不要**喊开发改行为；业务 `views` 仍须交棒 |

**禁止口令误解**：「一键全做 / 把双轨并刀 / 自动上线」≠ 合法；无波次 ID 口语 alone 开发拒做；一期禁自动发布。

## 1. 「无幻觉落地」靠什么（诚实口径）

**不能**口头保证数学意义的 100%。靠的是**硬闸**，不是自信：

1. **无交棒拒做** — 聊天碎片不算输入  
2. **缺项拒收** — 缺目标/范围/验收/轨指令 → 只列清单  
3. **Y2b 禁脑补** — 有疑问先问本尊；确认前不写产品决策进代码  
4. **口径冲突升法眼** — 交棒与 KB/现网冲突 → 停；法眼裁完回写交棒再干  
5. **回执强制** — 已实现 / 偏差 / 待拍板；禁止暗改需求装闭环  

本尊要的「100%」= **宁可停手提问，也不脑补做成**。

## 2. 联动触发

| 场景 | 谁动 | 下一棒 |
|------|------|--------|
| 需求定稿要双轨落地 | 言出法随出 `handoff-to-dev` | 唤明镜执行 |
| **工程阻塞**（握手/起服/VPN/缺表/仓路由/Vite 红屏/5666 起不来） | 言出法随**同轮**挂「## 明镜建议」或明镜顾问旁路 | 本尊按清单解阻；**不**自动改真码 |
| 交棒内口径打架 | 明镜停 + 问本尊/升法眼 | 更新交棒再开 |
| **轨 B 现网冲突**（交棒验收 vs 生产行为/字段） | 明镜停 → **升法眼**（见法眼 dual-track 指针） | 裁完回写交棒；禁静默按「我觉得」改现网 |
| 法眼勾 W/S/C | 言出法随收口③回写作战室 | 明镜不替代落评分（除非本尊点名） |
| 明镜回执「待拍板」/ 偏差码非 none | 言出法随用 §2c 模板改包 | 再交明镜 |
| **跨入口跳转 B 轨**（工作台→表单） | **默认 B1**（独立原型目录链跳）已拍 | 存量不合 B1 → 言出法随改；禁参考旧同页糊处理 |

### 2b. 明镜建议段（产品经理可读 · 强制结构）

```markdown
## 明镜建议
**一句话：** …
**原因（人话）：** …
**你现在只要做：** 1.… 2.…（≤5 步；找谁/点哪写清）
**解完喊我：** …（口令，如「握手好了」）
**我不会擅自：** 改真码 / 写产线库 / 装通关
```

### 2c. 偏差回写模板（明镜停手 → 言出法随改包 · v1.0.10）

明镜回执出现 `deviationCode` ≠ `none` 或「待拍板」非空时，**同轮**可贴给言出法随（或本尊转发）：

```markdown
## 请言出法随改包再交
- 波次 / ID：
- 偏差码：scope | acceptance | runtime | visual | await_pm | conflict_kb
- 一句话问题：
- 建议改交棒哪几节：（范围·做/不做 / 验收 / 通关证据 / 视觉锚点 / 待拍板）
- 明镜已停：是
- 是否需升法眼：是 / 否（轨 B 现网冲突默认「是」）
```

言出法随收到后：更新 PRD/交棒 → 本尊确认 → 再唤明镜；**禁止**口头「你先按我说的改」绕过改包。
