# 云效生命周期 10.2.5（Codex）

`完成开发`读取测试计划时，DevOps插件0.9.0仍可能发送不被服务端支持的form Content-Type，导致HTTP 500。现在先执行原有插件升级和一次重试；若仍是已知Content-Type错误，自动通过官方公开ListTestPlan接口发送JSON查询，并将真实计划交回原有范围解析流程。

- 新增仅查询计划的`yunxiao_testhub_read_api.py`：固定已验证中心域名、环境变量PAT、JSON请求、禁止重定向、分页和项目标识校验。其他Region或自定义端点尚未验证，明确阻断，不猜接口。
- JSON恢复成功记录`recovered-after-json-api`。成功且确实没有关联计划，与读取失败后跳过保持不同回执。JSON后仍遇可重试服务/连接错误时，保留完整诊断；权限、参数、响应结构或项目不一致均阻断。
- 完成开发执行器识别JSON成功回执；SDK错误原文中的`<nil>`不再被当作业务占位符拒收。所有模式仍要求对应测试任务完成后才能发布。
- 五个生命周期Skill版本标记和Codex包同步为10.2.5；增加读取恢复、权限、分页、响应校验和执行器回执测试。修正安装页检查脚本的旧锚点。Cursor历史包不变。

实机验证：在同一ONEOS项目中，原CLI升级重试仍HTTP 500，新JSON适配器成功读取测试计划；显式指定`ONEOS-1006 新故障处置0916`后成功读回目录。该计划22个目录没有端侧前缀，因此结果是`scope-unconfigured`，不能据此宣称已执行自测或测试通过。本次不修改云效单据或TestHub用例结果。

验证覆盖标准库自动化测试、交棒契约和Skill索引、每日更新脚本、语义路由、Codex包源文件一致性及安装页。团队成员仍须实际更新本机Skill并在新会话核对10.2.5，远端发布不代表所有电脑已升级。
