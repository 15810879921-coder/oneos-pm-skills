## 主链路

产品交付 →（业务口径）→（**系统架构** 按需）→ 开发落地 → **测级判定** → 测试验收（LIGHT/FULL）→ **【本尊上线】**  
测级矩阵：`references/test-trigger-matrix.md`（SKIP 免唤测，仍禁自称通过）

```text
何时喊总构官：跨服务拆分、AI 链路、人机边界、失败降级、长期演进契约
何时不喊：单页文案/纯样式、已有交棒且无架构歧义 → 直接工程官
```

## 供料与背书链（2026-08-19 扩编）

```text
知识典藏（唯一写入）→ 知识库 → 业务口径（只读检索裁决）
业务口径（算不算）  → 数据口径（怎么算）→ 口径卡 → 汇报/看板数字
数据口径 定版口径   → 知识典藏 入库沉淀
系统架构 ADR/契约   → 开发落地消费；定版结论可交典藏官沉淀
群聊语料            → 意图分析师草案 → 典藏官定版入库（意图分析师不写库）
```

上下游单向：合规官发现缺料报典藏官补，不自行写库；典藏官遇口径存疑报合规官裁，不自行定业务结论；度量官无合规官结论时不得自认业务性质；总构官不裁业务能不能做；意图分析师不写库、不定版。
