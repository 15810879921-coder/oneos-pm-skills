## 端侧标签（产品确认 · 肉眼区分）

创建任一【交付】时，除需求模块标签外，**必须**再打端侧标签，便于列表区分 Web 与小程序：

| 该条交付所属端 | 必打标签（显示名） |
|---|---|
| Web | `Web` |
| 小程序 | `小程序` |

规则：

1. 单端（`交付端=Web|小程序`）与双端（`共用服务` 拆出的两条）**一律**打对应端侧标签；禁止只建交付不打端标签。
2. 端侧标签与需求模块标签**并存**（多 tag 逗号拼接 PATCH）；不得用端标签替换模块标签，也不得省略模块标签（快轨仍同步需求标签）。
3. 标签 ID 须从云效实时标签列表按显示名唯一解析；`runtime-ids.json` 无缓存或 0/多命中时 **自动重拉一次**，仍失败则停，**禁止臆造 tagId**。项目尚无 `Web`/`小程序` 标签时，停下请产品先在云效建好同名标签后再继续。
4. 【分析】/【设计】建议同步打同一端侧标签（与所属交付一致），便于子项列表区分。
