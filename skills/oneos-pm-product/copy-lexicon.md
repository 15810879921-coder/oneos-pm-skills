# 文案词典 · 全局约束（分身强制 · 自动判断）

本尊定稿（2026-08-01）：产品侧凡用户可见「**审批**」一律改为「**审核**」。  
分身（言出法随）产出/改写需求、原型、标注、流程图、云效正文时**自动套用**；大脑答口径时同步。

---

## 1. 默认规则（先判再写）

| 判定 | 动作 |
|------|------|
| 用户可见中文（按钮、状态、Pill、列名、Toast、空态、PRD、流程图、验收文案、云效描述） | **审批 → 审核**（含词组整体替换，见 §2） |
| 新写 / 本轮改到的页面与 `.spec` | **必须**按审核口径落盘，禁止再写「审批」作业务态 |
| 代码标识符、API、DB 字段、英文枚举 | **不改**（如 `approvalStatus`、`leaseContract`）；展示层映射为「审核」文案 |
| 现网已发布流程**标题原文**需点名时 | 可写「现网流程名：租赁合同审批（产品口径：租赁合同审核）」；**新 PRD/原型只用审核** |
| 引用第三方/引擎文档专名（Warm-Flow 菜单「流程定义」等） | 专名可保留；业务语义仍用审核 |
| 用户消息/历史截图中的「审批」 | 引用时可保留原文，分身答复与落盘用审核 |

**禁止**：无脑全仓 `sed` 替换英文字段名、破坏编译；禁止把「审核」又写成「审批」充数。

## 3. 自动判断清单（动手前 5 秒）

写任何中文前过一遍：

1. 这话用户/业务会看见吗？→ **是** → 用「审核」。  
2. 这是代码/接口名吗？→ **是** → 保留 `approval*`，只改 label。  
3. 必须点名现网流程菜单原名吗？→ **是** → 原名+产品口径双写；否则只写审核。  
4. 会不会和「审核员/审计」混淆？→ OneOS 语境默认「审核」= 原审批语义；真·审计另写「审计」。  
5. 本轮改原型/PRD 是否仍残留「审批」状态文案？→ 有则同轮清掉。

## 4. 与三层状态 / Warm-Flow 的衔接

- 引擎实例仍可称 Warm-Flow；产品叙事：**审核流**（原审批流）。  
- 流程编码如 `leaseContract` 不变；展示名「租赁合同**审核**」。  
- 台账列「审核进度」；状态「待审核 / 审核中 / 审核通过…」。  
- 「待生效」等非审批词不受影响。

## 6. 能源口头别名 · 自动归一（本尊纠偏 · 2026-08-07）

### 6.1 清费 → 氢费

会议纪要 / 口述 / ASR 里偶发「**清费**」，产品正式口径一律为「**氢费**」。

| 判定 | 动作 |
|------|------|
| 能源 / 加氢 / 车辆氢费明细 / 氢费对账或协同语境下出现「清费」 | **自动当笔误**，产出用「氢费」（周报、PRD、简报、看板、云效描述、法眼答复） |
| 引用纪要原文需保留时可双写 | 「纪要写清费（产品口径：氢费）」；**正文叙事只用氢费** |
| 「清算 / 清缴 / 清理费用」等无关词 | **不**误替；仅当业务语境是加氢费用闭环时替换 |
| 仓库已有注记 | `hydrogen-fee-collab-*` 计划稿：「会上清费 = 产品侧氢费」——与本条一致 |

**禁止**：把「清费」写进新产品可见文案；禁止追问「是清费还是氢费」扰本尊（自动改）。

### 6.2 嘉兴站 → 加氢站

口头「**嘉兴站**」= 业务上的「**加氢站**」（嘉兴加氢站场景）。

| 判定 | 动作 |
|------|------|
| 周报 / PRD / 简报 / 对总监叙事提到嘉兴场景 | 写「**加氢站**」或「**嘉兴加氢站**」；避免只写「嘉兴站」让人以为另有业务线 |
| 必须点名现场地点时可保留 | 「嘉兴加氢站」优先；引用口述可双写「嘉兴站（加氢站）」 |
| 模块/路由专名（如 `oneos-web-h2-station*`、加氢订单 H5） | 仍用「加氢站 / 加氢订单」产品名，不另造「嘉兴站」菜单名 |

**禁止**：追问「嘉兴站是不是加氢站」；禁止把嘉兴口述写成与加氢站无关的第三套称呼。

### 6.3 清号 → 氢耗

会议 / 运维口述里的「**清号**」= 产品正式口径「**氢耗**」（百公里氢耗、按车/日抽检等）。

| 判定 | 动作 |
|------|------|
| 售后专项 / 运维抽检 / 车辆能耗语境下出现「清号」 | **自动归一**为「氢耗」（周报、PRD、简报、看板、云效描述、法眼答复） |
| 引用纪要原文需保留时可双写 | 「纪要写清号（产品口径：氢耗）」；**正文叙事只用氢耗** |
| 「清号」与车牌清册、单据号清理等无关语境 | **不**误替；仅当业务语境是车辆氢耗/百公里氢耗时替换 |

**禁止**：把「清号」写进新产品可见文案；禁止追问「是清号还是氢耗」扰本尊（自动改）。

### 6.4 探寻家 → 碳寻嘉

会议 / 转写里的「**探寻家**」= 产品正式名「**碳寻嘉**」（对外客户项目 · ESG/车辆实况平台）。

| 判定 | 动作 |
|------|------|
| 周报 / PRD / 汇报舱 / 纪要 / 云效描述出现「探寻家」 | **自动归一**为「碳寻嘉」 |
| 引用转写原文需保留时可双写 | 「转写写探寻家（产品口径：碳寻嘉）」；**正文只用碳寻嘉** |
| 云效已有「碳寻嘉」专名（如 CUST-*） | 保持「碳寻嘉」，勿再写探寻家 |

**禁止**：新产品可见文案再写「探寻家」；禁止追问扰本尊（自动改）。
