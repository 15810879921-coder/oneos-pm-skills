# 口径版本与生效日台账

> **进化任务**：`evo-dm-version-ledger`  
> **版本**：v1.0.0 · 2026-08-21  
> **硬闸**：改算法必须新开版本行 + 生效日（未知则 `since=null` + note）；**禁**静默改公式让历史数字漂移。

## 0. 怎么用

1. 每个口径卡 id 占一节；版本号 `v主.次`（破坏性变更升主版本）。  
2. `since` / `until`：ISO 日期或阶段名；未知 **null** + note（对齐 Y2c / 禁造事实）。  
3. 对外材料必须引用**生效中**版本；引用已 `until` 的版本须标明「历史口径」。  
4. 改卡：旧行填 `until`，新行 `since`，`changelog` 写一句人话。
