Skill 安装中心

每个能力单独一张卡：看用途，一键复制「安装 / 更新 / 发给 AI」。同事粘贴到终端，或整段丢给 Cursor / Codex 代跑即可。

产品三件套

一键安装 
npx skills add 15810879921-coder/oneos-pm-skills --skill YunxiaoPM -a cursor -a codex -g -y
npx skills add 15810879921-coder/oneos-pm-skills --skill AutoRDO -a cursor -a codex -g -y
npx skills add 15810879921-coder/oneos-pm-skills --skill oneos-autoprd -a cursor -a codex -g -y

王冕分身双 skill

推荐用官方脚本一次装齐 brain + twin；也可分别安装。

一键安装脚本 
curl -fsSL https://raw.githubusercontent.com/15810879921-coder/wangmian-skills/main/install.sh | bash

备注

  1. 需要 Node.js（可用 npx）。
  2. 云效相关 skill：浏览器先登录 https://devops.aliyun.com 。
