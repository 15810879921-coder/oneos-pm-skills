# 云效生命周期 Skill 10.2.14

本版完成 `执行测试流水线` 未落地的执行节点：候选发现之后可以生成受控事务、预检、只提交一次测试流水线并跟踪到终态。

## 变化

- 新增 `skills/yunxiao-release-operations/scripts/execute_test_pipeline.py`。
  - `prepare` 将唯一 `result=ready` 候选转换为 `test-pipeline` 事务计划。
  - `run` 串联候选读取、预检、一次 `flow-create-pipeline-run`、官方回读和轮询。
  - `monitor` 支持对已有执行 ID 继续跟踪，超时只报告未终态，不把它误判为失败。
- 网关将测试流水线执行与生产发布分离：测试事务必须绑定候选回执、上次成功部署基线、Codeup 待部署变更和 `flow-get-pipeline` 漂移守卫，不再要求生产 `releaseHandoffs`。
- 失败回执只使用官方执行读回中的失败/日志字段；没有日志时报告限制，不猜测根因。
- 五个云效生命周期 Skill 统一版本号为 `10.2.14`，索引与 Codex 包同步更新。

## 不变边界

- 流水线定义不创建、不复制、不修改、不删除；测试执行不推进需求、交付或发布状态。
- 测试流水线成功只证明测试环境技术执行成功，不能替代 QA 测试完成、生产发布或产品验收。
