> **硬闸**：增量补；**禁**一次性精装修 65 张；未知 `since` 一律 `null` + `note`，**禁编造日期**。

## 0. 触发（触碰哪张补哪张）

| 触发 | 动作 |
|------|------|
| 合规官裁决触碰某 `machine/rules/*.json` | 同轮升级该卡 `rules[]` 为对象 + 填条款级 `validity` |
| 本尊点名模块 / 入库单点名 | 只补点名卡 |
| 双周复评 | 从本表「待回填队列」抽 ≤5 张，不扫全库 |

**不做**：无触碰批量灌 `since: "2024-01-01"` 之类假完整。

## 1. 升级形态（对照 `kb-semantic-schema`）

存量字符串：

```json
"rules": ["对齐是交车门禁"]
```

触碰后：

```json
"rules": [
  {
    "text": "对齐是交车门禁",
    "metricRefs": ["pickup-paid-coverage"],
    "validity": {
      "since": null,
      "until": null,
      "supersedes": null,
      "note": "生效日未记入材料；口径见业财标杆卡"
    }
  }
]
```

卡头建议同轮补：`schemaRef`、`termRefs`（有则引 glossary id）。
