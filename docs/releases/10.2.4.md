# 云效生命周期 10.2.4：完成开发使用官方 CLI 参数

## 问题

10.2.3 的完成开发执行器能够校验交棒、测试任务和状态顺序，但计划示例仍使用 `--status`、`--description`、`--assigned-to`。当前 `aliyun-cli-devops` 的 `projex-update-workitem` 只接受 `--id` 与 `--biz-body`，因此真实执行会在写入前被 CLI 拒绝。

## 修复

- 测试交接、开发完成和需求状态动作统一把负责人、描述、格式与状态写入单个 `--biz-body` JSON。
- 完成开发执行器从 `--biz-body.description` 读取并校验交棒回执，同时保留旧计划中直接 `--description` 的只读兼容。
- 通用网关在阶段续跑时识别 `--biz-body.description`，只携带已经写入并官方回读的描述变化。
- 增加行为测试，禁止新完成计划再次生成当前插件不支持的三个参数。

## 验证

- 完成开发执行器单元测试覆盖真实 `--biz-body` 计划。
- 全仓生命周期测试、安装页检查、包构建和 manifest 哈希检查通过后发布。
