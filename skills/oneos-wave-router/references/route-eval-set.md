## 0. 怎么跑

1. 大改 `SKILL.md` / `SKILL-MAP.md` 分流表后，**同轮**对照下表心智自检  
2. **命中用例**（§1）：期望「喊谁」对上 → `Pass`；指错主入口 → `Fail`

5. 命中率：`Pass 数 / §1 总条数`（建议套 A 固定 10 条，见 §0.1）

## 2. 误指 fail 用例（指错人 = 暴击失败 · 须可复现）

> **判定**：出现「错误主入口」或「代办越权」即本条 **Fail（暴击）**；正确改指/拦下 = Pass。

| # | 错误行为（暴击） | 正确行为 | 自检 |
|---|------------------|----------|------|
| M1 | 「写需求」却指 `oneos-dev-delivery` / 开发落地 | 指 `oneos-pm-product` | |
| M2 | 「能不能做」却指产品交付改口径 | 指 `oneos-biz-rules`；产品不裁决业务法 | |
| M3 | 「无交棒改真仓」却指路「直接开干」 | 指开发落地并预期**拒做**；或先指产品出交棒 | |
| M4 | 「发版上线」却指测试验收或开发落地代推 | 拦回本尊；说明上线守闸休眠 | |
| M5 | 协调官自己改 PRD / 改码 / 写云效 | **禁代办**：只给口令，不办事 | |
| M6 | 「UI 评审完」指体验规范 = 验收通过 | 完成态只认 `oneos-qa-verify` | |
| M7 | 「云效建单」未问本尊就指「直接建」 | YunxiaoPM + **先问本尊** | |
| M8 | 把 `publish:war-room` 说成生产发版 | 纠正：作战室进展 ≠ 现网写变更 |
| M9 | 「给一线写怎么用」却只指产品交付出 PRD | 指 `oneos-briefing-aide`；落需求仍归产品交付 |
| M10 | 「给董事长做驾驶舱」却套一线培训骨架 | 改指 `pdf-report-plain-language` |
