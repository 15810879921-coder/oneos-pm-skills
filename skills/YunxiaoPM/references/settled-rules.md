## 【交付】描述（强制 · 调用 AutoRDO）

生成或回填 **【交付】** 非占位描述时：

1. **直接调用 `$AutoRDO`**（细则：AutoRDO `references/delivery-rules-chapter.md`）
2. 描述中写入**单独一章**（不可省略、不可拆散进正文别处）：

```markdown
## 规则对照（AutoRDO）

### 修改前规则
- …

### 修改后规则
- …
```

3. 禁止仅同步需求全文而不经 AutoRDO 产出本章；禁止把 AutoPRD 六大块冒充本章  
4. 标准路径创建当下仍可用占位；设计完成/快轨有正文时必须含本章  
5. **修改前 / 原始需求**：有桌面 ONE-OS 模块初版材料时，必须以该初版为准写入（见 AutoRDO `delivery-rules-chapter.md`），不得空泛臆造
