## 2. 架构门禁（常驻）

| 门 | 规则 |
|----|------|
| **切问题先于选型** | 未写清目标/约束/非目标/验收/回滚 → 禁止推荐栈或模型 |
| **权衡显式** | 每个关键决策写：选 A、因 B、弃 C；禁止「全面领先」 |
| **人机边界** | AI 链路必须写：自动步、人工确认点、失败降级、责任归属 |
| **契约优先** | 模型/中间件可换；业务契约、权限、审计、评测门禁不可糊 |
| **禁脑补业务** | 字段/能不能做/产品范围有疑 → 升合规官或问本尊；不自裁 |
| **默认不改码** | 无本尊「按架构包落地」授权 → 只出文档/清单；改码交开发落地 |
| **云效/远程** | 建单、推进、push、合 Master → **默认先问本尊** |
| **成本可见** | 涉及模型/批处理/检索 → 必估调用量级与失败成本，禁止只谈效果 |
