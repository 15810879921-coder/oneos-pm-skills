# 张兰总口径 · 产品方案图解轨

> 金样：张兰总《羚牛企业组织与人员主数据统一管理及多平台协同方案-图解版》（2026-09-03）。  
> **只管产品方案怎么交**，不是一线培训，也不是董事长大屏。  
> 一线培训仍走 [`zhanglan-skeleton.md`](zhanglan-skeleton.md)。决策层大屏走 `pdf-report-plain-language`。  
> **精髓**：一屏一个结论，图说话，字当标签。同一事实只说一次。细则进附录。

## 0. 写之前问自己

1. 这页要让人拍板什么？（定位 / 边界 / 机制 / 路线，不是「谁点哪个按钮」）
2. 哪一句是全篇锚？（只能出现一次；后文只准底栏再钉）
3. 哪些是主叙事、哪些必须降成附录表？

这三问答不出 → 不要动笔。

## 1. 一页节拍（强制顺序）

```text
第 1 页：材料性质 + 标题 + 一句核心目标锚
        + 开篇三卡（现状问题 / 统一方案 / 业务价值）
        + 总流程一条（5～6 步）
 → 01 系统定位 / 边界：谁负责、谁协同、暂不改变
 → 02 关键机制：箭头流程 + 规则表（时效 / 口径 / 门槛）
 → 03 一次变化怎么走：分轨短流程（如入职 / 调岗 / 离职）
 → 04 人怎么办：角色表 + 节奏表 + 一条原则底栏
 → 05 建设路线 + 上线门槛
 → 附录：对象规则表、部门底线表、异常表、验收勾选
```

可裁：没有三期就不要硬凑三期；机制页可与变化页合并。  
不可裁：核心目标锚、开篇三卡、边界（做/不做）、原则底栏、附录验收勾选。

**页数纪律**：主叙事 ≤ 6 屏；附录另计。超过就把部门/字段/异常降附录，禁止加页堆字。

## 2. 金样节拍（主数据方案 · 只记结构）

| 节 | 她怎么写 | 可复用句式 |
|----|----------|------------|
| 标题 | 「图解版｜先统一组织与人员，再联动…」 | `{事物}图解版｜先…再…` |
| 锚 | 一处维护、多端一致、业务联动、异常闭环 | 八字以内一组，可并列，禁段落 |
| 三卡 | 现状问题 → 统一方案 → 业务价值 | 每卡 3～4 条短句，禁止开篇沿革 |
| 总流程 | 统一维护 → 同步 → 变化触发 → 业务联动 → 异常 → 周度汇总 | 一条箭头，步骤名即结论 |
| 定位 | 钉钉 / OneOS / 下游；中间是主数据中心 | 谁是中心、谁只协同 |
| 边界 | OneOS 负责 / 钉钉负责 / 暂不改变 | 三行表，禁止「范围说明」长段 |
| 机制 | 实时 / 5 分钟 / 每日对账 | 规则进表，不进散文 |
| 原则底栏 | 人员状态与业务交接分开。账号按人事结果处理，未完成业务不得因停号消失。 | 每页最多一条；全篇同一原则不换词复读 |
| 路线 | 一期 2–3 周 → 二期稳定后 → 三期按项目 | 先统一数据，再迁流程 |
| 附录 | 主数据规则、部门转交底线、验收 10 条勾选 | 正文不铺部门说明书墙 |

## 3. 节模板

### 第 1 页

```text
材料性质：内部方案 · 图解版
标题：{方案名}
锚：{一句核心目标}
三卡：问题 / 方案 / 价值（各 3～4 条）
总流程：{5～6 步箭头}
```

### 页题（标题即结论）

```text
{序号} {主题}：{结论}
例：01 系统定位：OneOS 统一维护，其他平台协同使用
禁止：把离职方案拆到部门和岗位：谁转什么、谁负责、在哪转；停号与清单拆开
```

### 边界表

```text
谁负责 | 做什么
谁协同 | 做什么
暂不改变 / 不做 | 明确砍掉的
```

### 原则底栏

```text
原则：{一句}。{半句后果}。
```

全篇同一原则只许：第 1 页锚里出现一次 + 相关页底栏再钉一次。禁止在目标 / 问题 / 落地 / 要点 / 请确认里抄四遍。

### 待拍板

```text
序号 | 验收项 | □通过 □不通过
```

禁止「请确认事项」五段说明文。最多 3～5 条待拍板；其余进附录勾选。

## 4. 视觉门禁（缺一则 Fail）

```text
✅ 分区图解：流程用箭头；规则用表；原则用一条底栏
✅ 字是标签：框内 ≤4 条，条 ≤18 字
✅ 部门 × 岗位细则、字段清单、异常枚举进附录
✅ 待拍板用勾选表
✅ 已有汇报舱：一页滚完，目录锚点跳转
❌ 论文长标题
❌ Markdown/Word 说明书墙冒充图解（有卡片 ≠ 图解）
❌ 6 部门 × 双角色四字段铺正文
❌ 同一结论复读 ≥3 次
❌ 把培训节拍搬进产品方案
❌ 开篇「为提升协同效率，平台打通…」
❌ 擅自做成上一页/下一页/1／N 翻页器（除非本尊点名要幻灯/PDF）
❌ 箭头流程末步单独掉行（改 2×2 / 3×2 整行换）
```

落地形态：独立 PDF 图解可以分页。落到仓库已有汇报舱时，**换内容密度，不换壳**——仍一页滚完；禁止把「图解」听成翻页幻灯。**禁止另起一张**原型或「图解版」旁路页。

## 5. 反例（金样对照）

| 错法 | 为什么翻车 | 改成 |
|------|------------|------|
| 标题写成论文题 + 分号堆原则 | 第一屏读不完 | 标题即结论 |
| 「停号与清单拆开」在目标、落地、专节、请确认、要点里写四遍 | 套话 | 锚一次 + 底栏一次 |
| 6 个部门各做主管/接任人双卡 | 篇幅、纯文字 | 附录一张转交底线表 |
| 「请确认事项」1～5 段 | 不像拍板 | 验收勾选 |
| 竖版 3 页说明书，第 2 页超长 | 不像方案 | 横版 ≤6 屏主叙事 |
| 用《任务工单怎么用》12 节套方案 | 写成培训 | 本文件节拍 |
| 用本文件写一线操作入门 | 一线找不到按钮 | 改走培训骨架 |

## 6. 换方案速填

1. 一句锚是什么？（全篇只许这一句）
2. 问题 / 方案 / 价值三卡各 3 条是什么？
3. 谁是中心、谁只协同、一期明确不做什么？
4. 一次变化走哪几步？原则底栏写哪一句？
5. 哪些必须进附录，才能让主叙事 ≤6 屏？
