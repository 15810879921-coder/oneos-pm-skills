# 玉衢 / OneOS · 知识反哺 AI 协议（一页）

**版本**：v1.0 · 2026-08-21  
**署名**：王冕驱动 · 玉衡 · 产品交付 / 体验规范 / 知识典藏  
**用途**：内部执行与对外讲清「库如何让 AI 变准」；**不是**融资数字页。

---

## 1. 一句话

**知识库必须成为 AI 的运行时依赖**：可检索、可裁决、可弃权、可纠错回流——不是文档堆场。

## 2. 四条消费管道

| 管道 | 消费者 | 燃料形态 | 本期状态 |
|---|---|---|---|
| A Agent | Cursor 分身 / 法眼 | 机读规则卡 + glossary | 已跑（Grep） |
| B RAG | 数字员工 / 群报障 | 向量 chunk（须含 metrics） | 骨架有；chunker 待吃语义字段 |
| C 玉衢 | 客户本仓问答 | 闭环沉淀的知识资产 | 已产品化；纠错回流本期落地 |
| D 接库 | 一线问数 | dataSource 映射 + 只读 | 预留；真接未开（I 刹车） |

售前：**A/C 可讲机制**；**D 只作长期叙事**，不写进合同。

## 3. 五环闭环（强制）

```text
① 沉淀（缺口任务 / 裁决 / 会议）
 → ② 结构化入库（术语单源 · metrics · entities · validity）
 → ③ 窄检索消费（命中才答；未命中弃权）
 → ④ 信任分级展示（T1 建议 / T2 预填 / T3 可撤销自动 / T4 人确认）
 → ⑤ 错答回流（评测失败或用户点「不对」→ 缺口 / 改卡 → 复测）
```

缺 ⑤ = 库越厚 AI 越飘。

## 4. 硬闸

1. **禁造事实**：未知字段写 `null` + note，禁止脑补表名/公式。  
2. **术语单源**：定义只进 glossary / 等价单源；禁止各卡复制漂移。  
3. **聊天结论不入库不算数**：须进机读卡或玉衢资产才反哺下一轮。  
4. **高风险默认 T4**：资金、权限、删改禁止静默自动办。  
5. **出处必带**：回答须可点回卡 id / 资产 / 模拟源标注。  
6. **演示 ≠ 客户**：demo 种子分、模拟连接器禁止进融资/案例背书。

## 5. 体验（设计官）

- 主任务：让人**补一条口径 → 立刻多问得动一类题**。  
- 禁说明书墙教「语义层」；出处一条够。  
- 弃权文案可见：「库里没有」优于瞎编。  
- 纠错入口：答后「答得不对」→ 记成缺口（T1），不在黑盒里吞掉。

## 6. 玉衢产品落点（本期）

| 项 | 成功标准 |
|---|---|
| 体检报告收口 | 主 CTA 进看板办缺口；合作留资为次按钮 |
| 首屏差异 | 一眼能读到「不用先建知识库」 |
| 问答纠错回流 | 点「答得不对」→ 生成开放缺口任务 + 留痕 |
| 信任文案 | 模拟源 / 规划中标注保持；不作报价依据 |

## 7. OneOS 狗粮落点（并行，非本波必交）

- SEM-01：向量 chunker 消费 metrics/entities  
- 法眼触碰卡顺手回填 + eval-mini 失败必修库  
- dataSource 仅探针填值，禁写产线库  

## 8. 验收怎么认

- **工程绿**：交棒 + 测试证据块通过。  
- **反哺绿**：同一错答路径可复现「不对 → 缺口 → 闭环 → 再问变准」（至少演示账号可走通）。  
- **商业绿**：仍归 BP §8，本协议不替代付费验证。
