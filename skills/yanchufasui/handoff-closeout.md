## 0. 要解决啥

法眼写了一长串「提醒分身写作战室/评分」，分身收口只写「省时三行」→ **漏回写**。  
对齐后：**法眼勾选交棒码 → 分身收口第③行必须勾完或标 N/A**。

## 1. 交棒码（法眼输出 · 分身消费）

| 码 | 含义 | 分身动作（缺一则 Fail） |
|----|------|------------------------|
| **W** | 作战室战况 | `warRoomData.ts`（完成度/缺陷销账）± `defects[]` open ± 审计 LOG ± `publish:war-room` |
| **S** | AI-PM 评分 | 更新 `aiAgentPmScorecard.ts`（点名对象）+ 客观评价 + publish |
| **C** | 双 Skill 能力 | 更新 `skillCapabilities.ts`（八维/任务）+ publish |
| **B** | Bad Case | 写入言出法随 `eval-cases.md`「最近失败」（或补门禁） |
| **D** | 本轮应做 | ≤3 条可执行动作（落需求/改原型/…） |
| **N** | 本轮不做 | ≤3 条边界（禁偷偷云效 / 禁假裁决 / …） |

**触发（法眼勾选，无关则写 `N/A` 勿空着装没有）**

| 条件 | 必勾 |
|------|------|
| 漏洞修复 / 门禁补齐 / 原型补全 | **W** |
| 缺口 / 待拍板 / 优化 **非空** | **W**（`defects[]` open） |
| 触及一号位 / 组织默认 / 可观测 / AI 产品主线进展 | **S** |
| 触及 Skill 进化 / 能力短板 / 进化任务进展 | **C** |
| 本尊纠错口径 / 严重 Bad Case | **B** |
| 凡业务答复包 | **D** + **N**（可短） |

## 2. 法眼答复包 ·「给分身边界」短格式（强制）

替换原先散文提醒墙；业务题用：

```markdown
**给分身边界：**
- 交棒：W=? · S=? · C=? · B=?（是/否/N/A；是则一句锚点）
- 做（D≤3）：…
- 不做（N≤3）：…
```

示例：

```markdown
**给分身边界：**
- 交棒：W=是（DEF-xxx 入库）· S=N/A · C=N/A · B=否
- 做：① 缺口写入 defects ② publish:war-room
- 不做：① 不写云效 ② 不改无关模块
```

## 3. 言出法随 · 收口三行（消费交棒 · 强制对齐）

会话/任务可收口时（复杂任务 / 法眼交棒含 W|S|C|B=是 → **必须**写）：

```text
① 省时/返工：…
② 人工介入：…（本尊拍板 / Review / 确认项）
③ 交棒回写：W/S/C/B → 已落 | N/A | 本轮豁免（须写明）；禁止只口头「记得写」
```

**Fail**：法眼勾了 W/S/C/B=是，分身收口第③行未对应落盘/publish/记 Bad Case。

## 4. 同轮自检

```text
□ 法眼边界用了交棒码短格式（非散文墙）
□ 分身收口③覆盖全部「是」项
□ 有 W/S/C 则 publish:war-room 已跑（或书面豁免）
□ 有 B 则 eval-cases「最近失败」已写
```
