## 0. 分家口径（v1.4.74）

| 角色 | 做什么 |
|------|--------|
| **产品交付** | 需求 / PRD / **验收剧本** / 交棒包；改 **oneos-v2 原型**；**窄例外**：纯文案、纯样式、**点名的主题 CSS**（如 `oneos-v2-theme.css` Token/栅格，不含业务 `index.vue`） |
| **开发落地** | 正式可点对齐 + **`~/oneos-prod` 真仓业务码**；唯一输入 = 本交棒包 |
| **体验规范** | Token / Pattern / 展开收起原则；**不默改**真仓业务页 |
| **测试验收** | 证据块结论：通过 / 失败 / 阻塞 |
| 未唤开发落地时 | 产品交付仍可改原型（不打断日常）；**仍禁止**无包改真仓 `views` |
| **C 轨正式双轨** | 必须出交棒包；禁止只口头甩给开发落地 |

行为 / 流程 / 字段 / 门禁 → **不要**在交棒后又由言出法随偷偷改语义；要改就更新交棒包或 PRD 再交一次。

## 1. 何时必须出交棒包

- 本尊说「交明镜止水 / 交开发分身 / A_then_B / 本机真仓模拟」  
- 需求已定稿且需要**可点原型 +（可选）真码**双轨验收  
- 言出法随自觉范围已超「纯文案样式 / 点名主题 CSS」，应移交真仓实现  

## 1b. 波次边界（禁并刀 · 2026-08-15）

| 波次 | 层 | 交棒可写什么 | 禁止塞进同包 |
|------|----|--------------|--------------|
| **P0** | L0 规范 | Token / DESIGN / 禁第二套皮 · **证据包**（见 §2b） | 登录业务换皮、组织通讯录、壳/双套表单、租赁 |
| **P1** | L1 运行时 | 双套表单收口、壳、台账填满、H5 壳 | P0 未勾齐却开 P1 全量；拷 React 库 |
| **P2** | L2a 平台 | 登录 + 组织通讯录（现网能力对照） | 把「能登录本机」当成 P2 勾齐 |
| **P3+** | L2b / L3 / L4 | 按作战室 `dualTrackProgress` 通关条 | 无波次 ID 口头并刀 |

交棒标题**强制**带波次或进化任务 ID（如 `P0` / `evo-mj-vue-ds-replay`）。明镜只认 ID，不认「完成这一刀」口语 alone。

**本机登录红 toast / Connection reset**：优先查网关上游 IP / VPN（runtime 陷阱），**勿**先怪主题 CSS。连通性修复默认出 **runtime 工程包**，不并进 P0 产品勾齐。

```markdown

- 需求编号：

- 原型 id：

- 范围 · 不做：

- 验收 · 逆路径：
- 验收 · 门禁：
- 同页二次态：（台账类必填 · habits §3.0.7）
  - 状态机：`panel` / 等价（list | detail | edit …）
  - 组件路径：详情 / 编辑 / 新增（空壳也须列出）

  - 跨入口跳转目标：（若有工作台→表单）**默认 B1**：目标独立原型 id + 链跳入口 + 完整处理 UI（B2/B3 例外须本尊点名）
- 自检记录：（必点 URL + 已点绿项；P0 用 §2b。**不是**测试「通过」）
- 视觉锚点：（可选；现网 URL / 截图路径 / 须对表控件清单；像素对表·壳·登录·冻结列类**建议填**）
- 轨指令：A_only | A_then_B | B_only
- 真仓锚点：（可选；如 ln-one-os-web/apps/... 或现网 URL）
- 页面或接口路径：（氢/能/跨库必填；如 `/asset/hydrogen/ledger`）
- 已知缺口 / 待拍板：无
- 本尊确认轨指令：是 / 否
```

必填与拒收规则以明镜 `handoff-from-pm.md` 为准。言出法随出包前自检：缺验收/轨指令/波次 ID → **禁止**声称已交棒。  
台账类另检：缺「同页二次态」节或必点未列 → **禁止**声称已交棒（§3.0.7）。  
像素对表类：缺「视觉锚点」不拒收，但须在待拍板写明「缺锚点」或接受明镜回执 `deviationCode: visual`。

## 3. 交棒后言出法随做什么

1. 会话里贴交棒包全文（或路径）  
2. 提醒本尊新开/唤「明镜止水」执行（明镜默认不常驻）；口令速查见明镜 `twin-linkage` §0b  
3. 窄例外改皮：仅文案/样式；不动交棒内行为  
4. 明镜回执有「待拍板」/ `deviationCode` ≠ `none` → 按明镜 `twin-linkage` §2c「请言出法随改包再交」**更新交棒或 PRD**再交；禁止口头绕过  
5. 认回执 `mj-receipt` 块（waveId / passed / deviationCode / nextWave）；跑 `refresh-dual-track-auto` 时可抬半自动波次  

## 4. 不做

- 替明镜改 `~/oneos-prod` 真码（除非本尊点名言出法随临时代劳）  
- 无包声称「已交给开发」  
- 把云效【开发】树建单塞进本交棒（云效仍走 YunxiaoPM / 开发 Skill，另问本尊）
